GSD CONTENT TO CHATGPT — INSTALLATION

1. Unzip this download to a permanent folder on your computer.
2. Open Chrome and go to chrome://extensions.
3. Turn on Developer mode in the upper-right corner.
4. Click Load unpacked.
5. Select the unzipped gsd-chatgpt-extension folder.
6. Keep the extension enabled and remain signed in at chatgpt.com.

USAGE

Open a content item in GSD Content and click Generate Images. The extension opens a new ChatGPT conversation, inserts the prompt, and submits it. The GSD app separately watches the GSD Auto Assets Google Drive folder for finished images.

If the extension is not installed or enabled, Generate Images falls back to copying the prompt and opening ChatGPT for manual submission.

PRIVACY

The extension runs only on gsd-content.vercel.app and chatgpt.com. It stores a pending prompt locally for up to ten minutes and removes it after submission. It does not use the OpenAI API.
